----EJERCICIO INGENIERÍA INVERSA----

Los documentos adjuntos muestran la solución a un ejercicio de ingeniería inversa: dado un código 
ensamblador se procede a interpretar dicho código y rearmar el programa que lo ejecutaba. Los 
diferentes documentos del archivo quedan clasificados de la siguiente manera, y se recomienda 
su lectura/uso en la forma en que aquí aparecen:

- PROY_ING_INV.pdf --> Documento principal donde se describe el enunciado, proceso y metodología
	realizados, así como los resultados obtenidos.

- codigo_ensamblador.txt --> código ensamblador inicial y enunciado del proyecto.

- ASCII_ADDER_code.c --> código en c reintrepretado y resultado de los procesos llevados a cabo 
	en PROY_ING_INV.pdf. Constituye el código del programa y resultado final.

- ASCII_ADDER.exe --> programa compilado resultado del código anterior. Permite verificar los 
	resultados obtenidos.
